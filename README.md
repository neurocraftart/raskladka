# Раскладка по кривой

Бесплатный онлайн-инструмент для машинной вышивки: расставляет мотив вдоль кривой на равном расстоянии и отдаёт готовый файл для машины.

**Открыть инструмент:** https://neurocraftart.github.io/raskladka/

- Форматы: PES, DST, EXP, JEF, VP3, XXX, U01 и другие машинные форматы
- Подходит для Embird, Wilcom, PE-Design, Hatch, Bernina и других программ
- Готовые кривые: дуга, волна, круг, прямая — или своя кривая из файла
- До 4 разных мотивов на одной кривой в заданном порядке (АБ, ААБ, АБВ…)
- Файлы обрабатываются в браузере и никуда не загружаются

Подробная инструкция — на странице инструмента, в разделе «Как пользоваться».

Поддержать автора: [boosty.to/embroiderydesign](https://boosty.to/embroiderydesign)
